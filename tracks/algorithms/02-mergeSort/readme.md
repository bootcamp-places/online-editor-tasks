# mergeSort

Реалізуйте алгоритм Merge Sort (сортування злиттям), який отримує масив чисел і повертає НОВИЙ відсортований масив у порядку зростання. Початковий масив не повинен бути змінений.

Алгоритм працює за принципом «Divide & Conquer»: рекурсивно розділяємо масив на дві половини, поки не отримаємо масиви довжиною 0 або 1, після чого зливаємо (merge) їх у відсортованому порядку.

## Вимоги

- Повернути новий масив (не мутувати вихідний)
- Часова складність: O(n log n)
- Стабільність: порядок рівних елементів зберігається

## Приклади

```js
mergeSort([]); // []
mergeSort([5]); // [5]
mergeSort([3, 1, 2]); // [1, 2, 3]
mergeSort([5, -1, 10, 2]); // [-1, 2, 5, 10]
mergeSort([2, 2, 1]); // [1, 2, 2]
```

Реалізуйте допоміжну функцію `merge(left, right)`, яка отримує два ВЖЕ відсортовані масиви і повертає один відсортований результат. Основна функція `mergeSort` повинна:

1. Перевіряти базовий випадок (довжина 0 або 1)
2. Ділити масив на дві половини (slice)
3. Рекурсивно викликати `mergeSort` для лівої та правої половини
4. Повернути результат злиття `merge(leftSorted, rightSorted)`

## Поради

- Не змінюйте вихідний масив: використовуйте `slice`.
- Під час злиття порівнюйте перші елементи двох масивів (використовуйте два індекси або `shift`). `shift` спрощує код, але менш ефективний; індекси швидші.

## Додатково

Спробуйте після основного рішення оптимізувати злиття через індекси, щоб уникнути O(n^2) через багаторазові `shift`.
